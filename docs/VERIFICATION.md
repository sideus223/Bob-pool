# 품질 확인

## 2026-10-20 화면 개편과 추천 조건 표시

- 흰 배경·Noto Sans KR·밥풀이 기분 선택과 기본 프로필을 홈·추천·게시판·마이페이지에 적용했습니다. 일반 크기의 360·390 논리 픽셀 화면에서는 기분 5개를 한 줄로 보여주고, 글자를 확대하면 줄을 바꿉니다.
- 맵기와 예산은 접지 않고 표시합니다. 현재 선택 조건은 추천 버튼 위에 유지하며, 최대 예산은 공개 저장소의 기존 예상 가격 상한 기준을 사용합니다.
- 애니메이션 건너뛰기 체크는 기기에 저장합니다. 체크하지 않으면 밥풀이가 자기 밥솥의 가운데 화살표를 누르는 8단계 포즈를 재생하고, 결과 화면으로 페이드 전환합니다. 음식은 결과 화면에서 표시합니다.
- README의 6장은 현재 소스의 Flutter 위젯을 390×844 논리 픽셀에서 렌더링한 로컬 데모입니다. 게시판은 예시 데이터입니다. 이번에는 실기기·실서버 계정 쓰기를 다시 검사하지 않았습니다.
- Flutter 전체 테스트 114개 통과·기존 1개 건너뜀, 정적 분석 오류 없음, 코드 형식 검사 통과. 360·390 폭의 한 줄 기분 배치, 맵기·예산 선택, 320 폭·1.8배 글자의 줄바꿈과 애니메이션 분기를 포함합니다.
- Android 데모 debug APK 빌드 성공. 이번 커밋에는 소스와 README 이미지를 반영하며, 기존 빌드 12 Release 파일은 교체하지 않았습니다.
- 공개 저장소의 추천·학습·서버 로직은 유지하고 화면 및 표시 설정만 반영했습니다.

## 2026-10-15 App Check 연결·데모 APK 빌드 12

- [빌드 12 Release](https://github.com/sideus223/Bob-pool/releases/tag/v1.0.0-build.12)는 App Check가 적용된 연결 APK와 Firebase 없이 동작하는 데모 APK를 제공한다. 기본 실행 진입점으로 빌드했으며 실기기 점검용 진입점은 배포 APK에 사용하지 않았다.
- 실기기에서 Play Integrity 토큰 발급과 앱 ID 일치, 기존 로그인 유지·토큰 갱신, 게시판 서버 조회를 확인했다. 같은 로그인에서 App Check 헤더만 바꾼 Firestore 요청은 포함 200·누락 403이었다. 같은 가짜 로그인 정보로 비교하면 포함 시 자격 검증 오류 400, 누락 시 App Check 오류 401이었다. 실제 신규 로그인·회원가입·모든 화면을 재검사한 결과는 아니다.
- 사용자 승인으로 Identity Platform으로 전환하고 Authentication과 Firestore의 App Check를 적용했다. 무료 Spark를 유지하며 인증에는 하루 활성 사용자 3,000명 제한이 적용된다. Firestore 권한 규칙을 이번에 변경하지 않았다.
- 기존 Flutter 테스트 106개와 추가 데모 초기화 테스트 1개 통과, 기존 건너뛰기 1개 유지. 정적 분석, 연결·데모 release 빌드 성공. APK 크기와 SHA-256은 [App Check 검증 요약](evaluations/APP_CHECK_2026-10-15.json)에 기록했다.
- 한국어·일본어 다운로드 페이지는 빌드 12를 안내한다. App Check 미지원 구버전 연결 APK는 업데이트가 필요하며, 일반 에뮬레이터에서는 데모 또는 별도 등록한 개발용 디버그 공급자를 사용한다.
