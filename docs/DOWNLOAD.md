# Bob-pool APK 다운로드

사용할 버전을 선택해 다운로드하세요. Android 7.0 이상에서 사용할 수 있습니다.

| 버전 | 이용 방법 | 기록 저장 | 다운로드 |
|---|---|---|---|
| 일반 APK<br>서버 연결 | 회원가입·로그인 후 사용. 인터넷 연결 필요 | 밥풀 서버<br>계정별 저장 | [일반&nbsp;APK&nbsp;다운로드](https://github.com/sideus223/Bob-pool/releases/download/v1.0.0/bob-pool.apk) |
| 데모 APK | 로그인 없이 메뉴 추천·찜·선택·레시피 체험. 서버 게시판은 이용할 수 없음 | 기기에 저장 | [데모&nbsp;APK&nbsp;다운로드](https://github.com/sideus223/Bob-pool/releases/download/v1.0.0/bob-pool-demo.apk) |

두 버전은 같은 추천·학습 기능을 제공합니다. 같은 앱으로 설치되므로 한 기기에 별도 앱으로 함께 설치되지 않습니다.
