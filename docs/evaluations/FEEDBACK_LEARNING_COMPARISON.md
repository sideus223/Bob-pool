# 피드백 학습 적용 전후 측정

추천 알고리즘에서 학습을 적용하기 전후를 비교했습니다. 원본 추천과의 전체 비교에서 바뀐 예산 검사나 반복 조정의 효과를 학습 효과로 포함하지 않도록, 같은 추천 로직과 조건을 사용했습니다.

<br><br><br>

국물·양식·볶음·돼지고기 선호와 해산물 불호·구이 선호와 튀김 불호의 5가지 가상 취향을 정의했습니다. 취향에 맞는 학습 메뉴에는 긍정, 그 외 학습 메뉴에는 부정 반응을 부여했습니다.

<br><br><br>





## 측정 조건

스트레스·혼밥·최대 예산 25,000원·맵기 상관없음 조건을 사용했습니다. 예산을 통과한 메뉴를 학습용과 평가용으로 나누고, 평가용 메뉴의 반응은 학습에 사용하지 않았습니다. 돼지고기·해산물과 구이·튀김 비교에서는 해당 음식만 사용했습니다.

두 방식 모두 같은 평가 메뉴와 기본 점수, 10% 탐색 설정을 사용했습니다. 찜·선택 횟수·불호에 따른 직접 가점과 감점은 주지 않고, 음식 특징으로 학습한 결과의 반영 여부를 비교했습니다.

<br><br><br>





## 선호 음식의 추첨 확률

학습에 쓰지 않은 평가 메뉴에서 가상 취향에 맞는 음식의 추첨 확률을 더했습니다. 예를 들어 국물 선호에서는 평가용 국물 메뉴들에 배정된 확률을 합한 값입니다.

| 가상 취향 | 학습 / 평가 메뉴 수 | 학습 적용 전 | 학습 적용 후 | 변화 |
|---|---:|---:|---:|---:|
| 국물 선호 | 56 / 28 | 21.14% | 94.79% | +73.64%p |
| 양식 선호 | 56 / 28 | 0.84% | 20.61% | +19.77%p |
| 볶음 선호 | 56 / 28 | 33.79% | 70.06% | +36.28%p |
| 돼지고기 선호·해산물 불호 | 28 / 15 | 72.94% | 96.87% | +23.93%p |
| 구이 선호·튀김 불호 | 8 / 5 | 82.79% | 91.59% | +8.80%p |
| 시나리오별 단순 평균 | — | 42.30% | 74.78% | +32.48%p |

다섯 취향을 같은 비중으로 평균 냈을 때 선호 음식의 추첨 확률이 **32.48%p 상승**했습니다. 변화는 반올림 전 값으로 계산했습니다.

반응을 남긴 메뉴의 공통 특징이 다른 메뉴의 추천에도 반영됨을 확인했습니다. 다만 양식 선호는 학습 후에도 20.61%로, 다른 취향보다 반영 폭이 작았습니다.

이 결과는 가상 취향에 따른 추첨 확률의 변화입니다. 실제 팀원 만족도나 추천 정확도의 개선율은 아닙니다.
