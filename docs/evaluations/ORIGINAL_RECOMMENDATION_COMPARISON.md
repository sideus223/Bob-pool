# 원본 추천 알고리즘 대비 측정

밥풀원본에서 추천 서비스·취향 저장 서비스·메뉴 모델·메뉴 데이터의 변경 없는 복사본을 확보하고, 추천 알고리즘과 비교했습니다. 정적 분석과 비교 실행이 모두 통과했습니다. 총 235,000회 추천을 실행했습니다.

원본은 기분·상황·예산 일치를 단계별로 확인하고, 처음 후보가 나온 단계에서 `shuffle()`로 한 메뉴를 고릅니다. 불호와 현재 메뉴를 제외하고 필요하면 제외 조건을 완화합니다. 맵기는 선택한 값으로 유지하지만 예산은 후보가 없을 때 완화할 수 있습니다. 원본의 좋아요 저장 기능은 추천 점수에 사용되지 않습니다.

## 추천 다양성과 반복

앱의 기분 5개와 상황 6개를 조합한 **모든 30개 조건**에서 최대 예산 25,000원·맵기 상관없음을 입력했습니다. 조건별로 100회 추천을 20번 실행해 두 방식 합계 120,000회 추천을 비교했습니다. 각 실행은 취향과 노출 기록이 없는 상태로 시작합니다.

새로운 좋아요·선택·불호는 추가하지 않았습니다. 현재 알고리즘은 노출 기록을 갱신하고 추천마다 시간을 1분씩 진행했습니다. 원본은 최근 기록을 추천에 사용하지 않습니다. 별개의 추천 요청을 비교하므로 두 방식 모두 재추천 버튼의 현재 메뉴·세션 제외는 적용하지 않았습니다. 각 조건과 실행에 같은 비중을 주어 평균을 계산했습니다.

| 지표 | 원본 | 추천 알고리즘 | 변화 |
|---|---:|---:|---:|
| 100회당 서로 다른 메뉴 수 | 평균 3.43개 | 평균 59.71개 | 약 17.4배 · 1,639.2% 증가 |
| 같은 메뉴의 연속 추천률 | 53.46% | 2.02% | 51.44%p 감소 |
| 비슷한 음식의 연속 추천률 | 70.46% | 6.72% | 63.73%p 감소 · 상대적으로 90.5% 감소 |
| 100회당 서로 다른 음식 형태 수 | 평균 1.70종 | 평균 6.77종 | 5.07종 증가 |
| 메뉴 예상 가격 상한이 최대 예산보다 큰 비율 | 66.67% | 0.00% | 66.67%p 감소 |

변화는 반올림 전 원본 값으로 계산했습니다.
비슷한 음식은 같은 메뉴이거나, 둘 다 면·국물·빵·샐러드 중 같은 종류인 경우입니다. 그 외 음식은 음식 형태와 조리법이 모두 같을 때 유사하다고 판단했습니다.
연속 추천률은 각 실행의 인접 추천 쌍 99개를 분모로 계산했습니다.

## 다른 예산에서의 확인

특정 예산의 영향도 확인했습니다. 예산별로 모든 30개 조건에서 50회 추천을 5번 실행했고 두 방식 합계 75,000회를 추가 측정했습니다. 아래 메뉴 수는 **50회당 평균**이므로 위의 100회당 메뉴 수와 직접 비교하지 않습니다.

| 최대 예산 | 원본 메뉴 수 | 제안 방식 메뉴 수 | 원본의 비슷한 음식 연속률 | 제안 방식의 비슷한 음식 연속률 |
|---|---:|---:|---:|---:|
| 10,000원 | 9.30개 | 20.16개 | 48.50% | 17.54% |
| 15,000원 | 7.99개 | 37.11개 | 49.27% | 6.46% |
| 20,000원 | 3.43개 | 39.08개 | 71.29% | 6.03% |
| 25,000원 | 3.43개 | 39.08개 | 70.94% | 6.03% |
| 50,000원 | 13.03개 | 40.53개 | 38.49% | 5.43% |

검사한 모든 예산에서 평균 메뉴 수가 늘고 비슷한 음식의 연속률이 낮아졌습니다. 다만 개선 배율은 예산에 따라 달랐습니다.

## 같은 가상 취향 기록을 반영한 추천

국물·양식·볶음·돼지고기 선호와 해산물 불호·구이 선호와 튀김 불호의 5가지 가상 취향을 정의했습니다. 스트레스·혼밥·25,000원·맵기 상관없음 조건에서 두 방식 모두 같은 긍정·부정 메뉴 기록을 제공했습니다.

현재 최대 예산을 통과하는 메뉴 ID를 정렬하고, 각 시나리오에서 순서가 3의 배수가 아닌 메뉴 중 최대 64개를 반응 기록으로 사용했습니다. 원본의 좋아요·불호 키에 해당 ID를 저장했고, 현재에는 같은 찜·불호 ID와 그 기록으로 학습한 모델을 제공했습니다. 새로운 음식의 추천 확률 변화만 분리한 실험은 아닙니다.

추천은 매번 전체 메뉴 100개에서 수행했습니다. 조건·취향이 고정된 상태에서 각 시나리오를 피드백 전후, 원본·현재 각각 2,000회씩 실행해 합계 40,000회를 측정했습니다.

| 가상 취향 | 원본 피드백 후 선호 음식 비율 | 제안 방식 피드백 후 선호 음식 비율 |
|---|---:|---:|
| 국물 선호 | 0.00% | 99.30% |
| 양식 선호 | 0.00% | 84.40% |
| 볶음 선호 | 100.00% | 97.30% |
| 돼지고기 선호·해산물 불호 | 0.00% | 90.00% |
| 구이 선호·튀김 불호 | 0.00% | 25.35% |
| 시나리오별 단순 평균 | 20.00% | 79.27% |

다섯 시나리오를 같은 비중으로 평균 낸 선호 음식 추천 비율은 **59.27%p 상승**했습니다. 가상 불호 음식의 추천 비율은 평균 40.00%에서 3.98%로 낮아졌습니다. 재료·조리법 비교에서 양쪽 모두에 속하지 않는 음식은 중립으로 계산했습니다.

현재 알고리즘의 피드백 전 선호 음식 비율은 평균 18.37%, 피드백 후는 79.27%였습니다. 원본의 평균은 피드백 전후 모두 20.00%였습니다. 원본이 고른 높은 가격 범위 메뉴가 이번 반응 기록에 포함되지 않은 영향도 있습니다. 직접 가점·감점과 학습을 함께 제공했으므로 59.27%p를 학습 모델 단독의 효과로 표현하지 않습니다.

이 결과는 인위적인 취향에 따른 **추천 음식의 구성 비율**입니다.
