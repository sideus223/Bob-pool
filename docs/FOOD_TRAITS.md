# 음식 특징 기준

기존 메뉴 100개의 레시피를 읽고 `food_traits`를 추가했다. 메뉴 이름·가격·기분/상황 태그·재료·레시피 본문은 바꾸지 않았다. 이 자료는 추천 모델의 입력이며 식당의 실제 성분이나 알레르기·영양·채식 조건을 검증하는 자료가 아니다.

| 필드 | 기준 |
|---|---|
| `main_ingredients` | 완성 음식의 주재료 계열. 소고기·돼지고기·닭고기·해산물·달걀·콩/두부·채소·유제품·곡물 중 여러 개 가능 |
| `cooking_method` | 볶음·튀김·구이·끓임·찜·생식·굽기·삶기 중 주된 조리 성격 하나 |
| `food_form` | 밥·면·국물·빵·샐러드·일품·간식·기타 중 주된 식사 형태 하나 |
| `taste_tags` | 짭짤함·달콤함·기름짐·새콤함 중 레시피로 설명할 수 있는 성격. 여러 개 가능 |

‘구이’는 팬/직화로 익힌 고기·생선·토스트 등을, ‘굽기’는 피자처럼 반죽을 굽는 음식을 구분한다. ‘끓임’은 국·찌개·조림·소스 끓이기, ‘삶기’는 삶거나 데친 재료를 완성 음식으로 사용하는 경우다. ‘생식’은 샐러드·초밥·샌드위치·비빔밥처럼 준비한 재료를 조립하거나 섞는 형태를 포함한다. 모든 재료가 날것이라는 뜻은 아니다.

여러 조리 과정이 있는 음식은 주된 성격 하나를 사용한다. 카츠동은 튀긴 돈까스를 달걀 소스에 끓여 마무리하므로 끓임, 양념치킨은 튀김으로 분류했다. 국밥은 밥이 있어도 국물, 라멘·우동은 국물이 있어도 면, 포케는 밥으로 분류했다. 이러한 편집 기준은 실제 사용자 검증으로 최적화한 분류가 아니다.

주재료 목록에는 육수·양념·선택 곁들임 전체를 넣지 않는다. 레시피에 대체 가능한 주재료가 있으면 가능한 계열을 함께 넣는다. 예를 들어 순두부찌개는 바지락 또는 돼지고기를 사용하므로 해산물과 돼지고기를 함께 기록한다. 새우젓·멸치육수 등이 목록에서 빠져도 해당 성분이 없다는 뜻이 아니다.

| 예시 | 주재료 | 조리법 | 형태 |
|---|---|---|---|
| 제육볶음 | 돼지고기 | 볶음 | 일품 |
| 닭갈비 | 닭고기·채소 | 볶음 | 일품 |
| 생선구이 | 해산물 | 구이 | 일품 |
| 비빔국수 | 채소·달걀·곡물 | 삶기 | 면 |
| 크림파스타 | 유제품·돼지고기·곡물 | 끓임 | 면 |

모델은 메뉴 ID나 이름의 문자열을 학습하지 않는다. 음식 특징과 분류·맵기·포만감·가격 조건 및 기분/상황과 음식 형태의 조합을 사용한다. 같은 특징의 메뉴는 같은 입력을 갖고 다른 특징은 별도 자리에 들어간다. 특징 순서는 [고정 목록](../lib/models/learning_feature_schema.dart)에 있으며, 뜻이나 순서를 바꿀 때 모델 버전도 바꿔야 한다.
